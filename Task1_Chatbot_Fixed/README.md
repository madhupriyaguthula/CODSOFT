# Rule-Based Chatbot

## Description
A simple GUI-based chatbot developed using Python and Tkinter. The chatbot responds to user inputs using predefined rules and pattern matching.

## Features
- Interactive GUI
- Greeting responses
- Date and Time information
- Help menu
- Exit functionality

## Technologies Used
- Python
- Tkinter

## How to Run

1. Clone the repository
2. Open chatbot.py
3. Run:

```bash
python chatbot.py
```

## Output

A GUI-based rule-based chatbot that interacts with users through predefined responses. The chatbot can recognize greetings, respond to simple conversational queries, display the current date and time, provide information about itself, and exit when requested by the user.

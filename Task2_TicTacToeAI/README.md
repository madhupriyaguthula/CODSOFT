# Tic-Tac-Toe AI

## Description

A GUI-based Tic-Tac-Toe game developed using Python and Tkinter where a human player competes against an AI opponent. The AI uses the Minimax algorithm to determine the best possible move, making it impossible to defeat.

## Features

* Interactive graphical user interface
* Human vs AI gameplay
* Minimax algorithm implementation
* Win, lose, and draw detection
* Automatic game reset

## Technologies Used

* Python
* Tkinter
* Minimax Algorithm

## How to Run

1. Open the project folder.
2. Run:

```bash
python tictactoe.py
```

## Output

A fully functional Tic-Tac-Toe game where the player competes against an AI opponent capable of making optimal decisions using the Minimax algorithm.
